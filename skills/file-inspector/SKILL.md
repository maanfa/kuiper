# 文件查看器

打开并浏览 `.cztr` 地形包文件，查看内部瓦片索引、元数据及图层配置信息。

## 功能入口

侧边栏 → 文件查看器

## 界面布局

左侧为**文件浏览区**，右侧为**信息面板**，中间可拖拽调整比例。

### 文件浏览区

- 支持同时打开多个 `.cztr` 文件，以标签页形式管理
- 每个文件下方包含**表切换**（tiles / metadata）和**数据表格**
- `tiles` 表支持模糊搜索（按 `z/x/y` 坐标）
- `metadata` 表显示键值对，其中 `layer_json` 行可点击查看详情

### 信息面板

根据选中内容自动切换显示模式：

| 场景 | 显示内容 |
|------|---------|
| 未打开文件 | 空白提示 |
| 打开文件后未选中行 | 数据库概要（文件名、路径、大小、瓦片数、级别范围、坐标范围） |
| 选中 `tiles` 行 | 瓦片坐标（z / x / y）及 BLOB 数据大小，支持「保存瓦片数据」导出 |
| 选中 `metadata` 中 `layer_json` 行 | 完整 JSON 树形展示，支持折叠展开、按值复制、下载 JSON 文件 |

## 操作说明

### 打开文件

点击顶栏文件选择器（仅接受 `.cztr` 扩展名），或拖拽文件到窗口。

### 关闭标签

- 点击标签上的 **✕** 按钮关闭单个标签，弹出确认对话框
- 点击标签栏右侧的 **✕** 按钮关闭全部标签
- 顶栏的「关闭免确认」开关可跳过确认弹窗

### 查看 JSON

1. 在 `metadata` 表中切换到该表
2. 点击 `key` 列为 `layer_json` 的行
3. 右侧面板显示完整 JSON 树（默认折叠至第一层），点击节点展开
4. 工具栏提供**复制整段 JSON** 和**下载为 `layer.json` 文件**
5. 点击任意值（字符串/数字/布尔）可单独复制该值

### 查看瓦片信息

1. 切换到 `tiles` 表
2. 点击任意行，右侧显示瓦片坐标和 BLOB 数据大小
3. 点击「保存瓦片数据」按钮可选择路径导出原始 `.terrain` 文件

## 技术实现

### 数据查询

- 表格数据通过 IPC `cztr:query` 获取，对文本列做 80 字符截断以保证行高一致，BLOB 列显示 `[RAW BLOB]`
- 信息面板通过 IPC `cztr:query-row` 获取完整行数据（不截断）
- 瓦片 BLOB 大小通过 `SELECT length(data)` 查询

### JSON 查看器

- 基于 `vue3-json-viewer` + `clipboard` 实现，支持语法高亮、节点折叠
- 默认折叠至第一层（`expand-depth="1"`）
- 复制反馈通过底部状态栏绿色标签显示，3 秒自动消失

### 表格组件

- `SimpleTable`：基于原生 `<table>` 实现，毛玻璃固定表头、圆角边框
- 数据表格支持行点击选中，重用同一套表格样式

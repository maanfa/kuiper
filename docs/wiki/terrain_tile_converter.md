# 地形切片转换器

Cesium Quantized TerrainMesh 格式的切片打包与解包工具。支持将瓦片目录（TMS 结构）打包为单个 `.cztr` 容器文件，或从 `.cztr` 容器还原为瓦片目录。

## 功能入口

侧边栏 → 地形切片转换器

## 打包（切片 → 单文件）

将包含 `layer.json` 和 `*.terrain` 文件的瓦片目录打包为一个 `.cztr` 文件。

### 操作步骤

1. 选择**输入目录**（包含 `layer.json` 的地形切片根目录）
2. 确认**输出文件**路径（自动生成为输入目录同级的 `目录名.cztr`）
3. （可选）展开**高级参数**，调整每批处理数量（默认 400）
4. 点击**提交**，在确认弹窗中核对信息后再次点击**提交**

### 文件格式

`.cztr` 为 SQLite 数据库容器，内含两张表：

- `tiles(z, x, y, data BLOB)`：瓦片二进制数据，按 TMS 坐标索引
- `metadata(key, value)`：元数据包括 `layer.json` 全文、瓦片范围、缩放级别、瓦片数量、创建时间等

## 解包（单文件 → 切片）

从 `.cztr` 文件中还原 TMS 瓦片目录。

### 操作步骤

1. 选择**源文件**（`.cztr` 文件）
2. 选择**输出目录**（自动生成/手动指定）
3. （可选）勾选**每次执行前清理目标文件夹**
4. （可选）展开**高级参数**，调整每批处理数量
5. 点击**提交**

### 还原结果

输出目录中将生成 `layer.json` 及完整的 TMS 目录结构 `{z}/{x}/{y}.terrain`。

## 注意事项

### SMB/网络路径性能

工具已对网络存储（NAS、SMB/UNC 共享）做了专项优化：

- **文件读取与数据库写入**：在后台工作线程中并行执行，不阻塞界面操作
- **主数据库构建**：在本地临时目录完成，处理结束后整体复制至目标路径，避免逐文件网络 I/O
- **最终文件复制**：异步执行，界面不冻结

尽管已做优化，网络路径下的素材目录扫描和最终文件复制仍需等待网络响应，这是 SMB 协议逐次握手和机械硬盘寻道的固有延迟，与工具本身无关。

### 数据一致性

- 打包时请确保输入目录中的瓦片文件完整、未被其他程序修改
- 解包时如勾选"清理目标文件夹"，会在开始前删除目标目录全部内容
- `.cztr` 文件使用 SQLite 格式，可用任意 SQLite 客户端直接查看

### 并行数

- Toolheader 中的**并行数**控制工作线程数量（默认 3，范围 1-50），影响文件 I/O 并行度
- 高级参数中的**每批数量**控制每批处理多少文件后让出事件循环（默认 400），影响 UI 响应平滑度

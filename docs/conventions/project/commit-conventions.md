# 提交约定

## 格式

```
<prefix>: <中文描述>
```

- 前缀与描述之间以 `: `（英文冒号 + 空格）分隔
- 描述使用中文，简洁说明变更内容
- 首行控制在 72 字符以内

## 前缀

| 前缀 | 用途 |
|------|------|
| `feat` | 新功能 |
| `fix` | 缺陷修复 |
| `docs` | 文档更新 |
| `refactor` | 代码重构（不改变功能行为） |
| `chore` | 工程杂项（依赖更新、构建脚本调整等） |
| `style` | 代码风格（格式化、空格等，不影响逻辑） |
| `test` | 测试相关 |
| `perf` | 性能优化 |

## 示例

```
feat: 新增地形切片生成器
fix: 修复 asar 膨胀导致安装包体积异常
docs: 更新 README 技术栈说明
refactor: IPC push 驱动状态同步，替代手动写 store
chore: 升级 electron-builder 至 26.x
```
